All notable changes to this project will be documented in this file.

## Unreleased

## 2.0.6 - 2023-08-31

### Fixed
- Applying checklist on a list with nested lists turned only the outer list into a checklist. #TINY-9998

## 2.0.5 - 2023-06-13

### Fixed
- Checklist toggling was possible on non-editable elements #TINY-9469

## 2.0.3 - 2023-03-16

### Fixed
- Checklist toggling on selection with lists turned them into unordered lists instead of checklists. #TINY-9499

## 2.0.2 - 2022-11-23

### Fixed
- Checklist toggling did not preserve selection when used on an existing list. #TINY-9289

### Removed

- Removed support for Microsoft Internet Explorer #TINY-8245
